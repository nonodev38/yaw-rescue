Pourquoi Yaw Rescue existe

Beaucoup de joysticks souffrent d’un yaw erratique : jitter, bruit au centre, oscillations imprévisibles. Yaw Rescue corrige ces défauts avec un traitement de signal professionnel, pilotable depuis ton smartphone en WiFi.

X‑Plane 11/12 FlyWithLua NXT Python 3 + HTTPS Interface mobile

Le problème que Yaw Rescue répare

Les joysticks milieu de gamme ont souvent un axe de yaw bruyant qui provoque :

  • Mouvements de gouvernail erratiques
  • Oscillations rapides (“jitter”) dues aux potentiomètres usés
  • Sauts de yaw imprévisibles en vol

Yaw Rescue applique :

  • Lissage du signal
  • Filtre anti‑bruit
  • Zone morte centrale
  • Auto‑coordination
  • Yaw damper

Fonctionnalités

  • Interface mobile (smartphone/tablette)
  • Trim universel pitch/roll/yaw
  • Contrôle des volets
  • Profils par avion
  • HTTPS + QR code

Installation

  1. Copier le dossier Yaw Rescue dans FlyWithLua
  2. Placer yaw_rescue.lua dans Scripts/
  3. Lancer start_panel.bat
  4. Scanner le QR code
