Pourquoi Yaw Rescue existe

Beaucoup de joysticks souffrent d'un yaw erratique : jitter, bruit au centre, oscillations imprévisibles causées par des potentiomètres usés. Yaw Rescue applique un traitement de signal pensé pour le vol, piloté depuis un smartphone en WiFi, sans rien installer côté téléphone.

Ce que Yaw Rescue corrige

Symptôme observé
Traitement appliqué
Mouvements de gouvernail erratiques
Lissage du signal en continu

Filtre anti-bruit adaptatif

Fonctionnalités

Interface mobile
Pilote les réglages depuis ton smartphone ou ta tablette, sans quitter le siège pilote.
Trim universel
Ajuste le pitch, le roll et le yaw depuis un seul panneau, avec retour en temps réel.
Contrôle des volets
Gère la position des volets directement depuis l'interface, sans repasser par le cockpit physique.
Profils par avion
Enregistre un réglage par appareil et recharge-le automatiquement au prochain vol.
Connexion HTTPS + QR code
Connecte le téléphone en scannant un QR code, sur ton réseau local uniquement.

Installation

  1. 1
    Copier le dossier du plugin

    Place le dossier Yaw Rescue dans ton répertoire FlyWithLua.

  2. 2
    Ajouter le script

    Copie yaw_rescue.lua dans le dossier Scripts/.

  3. 3
    Lancer le panneau de contrôle

    Exécute start_panel.bat pour démarrer le serveur local.

  4. 4
    Connecter le smartphone

    Scanne le QR code affiché pour ouvrir l'interface mobile sur ton réseau.
